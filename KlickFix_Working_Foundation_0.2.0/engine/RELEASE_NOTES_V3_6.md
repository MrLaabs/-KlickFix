# FixIQ v3.6 Release Notes

## Real Probability Calibration

v3.6 gives FixIQ a controlled learning path from diagnosis to verified repair outcome.

### Added
- Verified repair-outcome schema
- Outcome validation and deduplication
- Calibration statistics
- Reliability bins
- Brier score
- Log loss
- Bayesian smoothing
- Sample-weighted probability adjustment
- Calibration readiness thresholds
- v3.5 diagnostic integration
- Explicit provisional/calibrated status

### Deliberately not added yet
- Live customer outcome collection UI
- Supabase persistence
- Automatic model retraining
- Manufacturer-wide failure-rate claims
- Any fabricated real-world statistics

Those require authoritative production data and are intentionally deferred.
