# FixIQ v4 Release Notes

## v4.0.0 — AI Orchestration Layer

### Added
- Unified diagnostic orchestration API
- Controlled safety gate
- Evidence summary
- Ranked next-best-question layer
- Customer explanation layer
- Session creation and immutable answer application
- Calibration/reporting integration
- Explicit orchestration hierarchy protecting deterministic intelligence

### Preserved
- v3.3 model intelligence
- v3.4 error-code intelligence
- v3.5 parts compatibility intelligence
- v3.6 probability calibration
- All prior regression suites

### Important
v4 does not yet call a live external LLM API. It establishes the safe orchestration boundary first so a future AI adapter cannot bypass FixIQ's deterministic safeguards.
